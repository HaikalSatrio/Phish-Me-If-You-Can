# Research scope

Build Guidelines is the governing product specification. The engine supports authorized defensive analysis, synthetic identities, test accounts, and permitted public evidence. Scenarios remain local research objects.

This milestone implements evidence handling and an experimental five-dimension PES. It does not implement credential collection, malware delivery, or automatic message delivery.

## Next milestones

1. Extend evidence validation, calibrated identity matching, and provenance review based on evaluation.
2. Build evidence-bounded personas with observed, contextual, and unknown fields.
3. Introduce separate scenario, persona, and judge interfaces with fixed outcome definitions.
4. Add repeated simulations, generic baselines, versioned prompts, experiment metadata, and SSR.
5. Define coalition value before adding Shapley attribution.
6. Add explicit graph semantics and cost-based remediation evaluation.
7. Connect collectors and a nontechnical GUI to the stable core.

PES, identity confidence, SSR, and attribution remain separate. Human predictive validity requires a separate evaluation design. No Arsenal edition, deadline, or acceptance claim is established by this prototype.
